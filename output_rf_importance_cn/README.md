# 图8 随机森林特征重要性中文重绘

本目录用于重新绘制论文图件“随机森林失效模式识别的特征重要性”。图内仅保留两个子图标题：

- （a）随机森林不纯度重要性
- （b）置换重要性

## 数据来源

- 左图数据采用用户提供的精确随机森林不纯度重要性数值，并按数值从大到小排序。
- 右图优先从项目根目录下的 `Origin_RF特征重要性_整理数据.xlsx` 中读取工作表 `右图_截图反读近似`。
- 若输入 Excel 文件或指定工作表不存在，脚本会使用内置备用数据。
- 为便于 GitHub Pull Request 文本差异查看，已将左右图数据分别保存为 UTF-8 编码 CSV：
  - `图8_左图_不纯度重要性.csv`
  - `图8_右图_置换重要性.csv`

## 右图近似数据注意事项

右图当前备用数值为根据原图坐标比例整理的近似值，仅用于复现原始截图的柱形比例关系。若后续获得原始置换重要性计算输出，应直接替换脚本顶部的右图数据，或提供包含 `右图_截图反读近似` 工作表的原始 Excel 数据文件后重新运行脚本。

## Python 环境依赖

推荐使用 Python 3.10 或更高版本，并安装以下依赖：

```bash
python -m pip install matplotlib pandas openpyxl pillow
```

字体方面，脚本会依次尝试使用：

1. SimSun
2. Microsoft YaHei
3. Noto Sans CJK SC
4. Source Han Sans SC

如系统缺少上述中文字体，建议先安装其中一种字体后再生成正式图件，以避免中文显示异常。

## 本地生成图件命令

在项目根目录运行：

```bash
python output_rf_importance_cn/图8_随机森林特征重要性_中文.py
```

脚本运行后会自动检查输出文件是否存在且文件大小大于 0，并在终端打印每个文件的完整路径。

## 生成文件

本地运行脚本后最终会生成以下文件：

- `图8_随机森林特征重要性_中文.svg`
- `图8_随机森林特征重要性_中文.pdf`
- `图8_随机森林特征重要性_中文.png`
- `图8_随机森林特征重要性_中文.tif`
- `图8_随机森林特征重要性_中文数据.xlsx`
- `图8_左图_不纯度重要性.csv`
- `图8_右图_置换重要性.csv`

其中 SVG、PY、CSV 和 README 为文本文件，适合纳入 Git 版本控制；PDF、PNG、TIF 和 XLSX 为本地生成文件，已通过 `.gitignore` 排除，不应提交到 GitHub Pull Request。

## 推荐使用方式

- 推荐使用 `SVG` 作为后续编辑文件，可在 Adobe Illustrator、Inkscape、CorelDRAW 等软件中继续编辑文字、柱形、坐标轴等矢量对象。
- 推荐使用 `TIF` 作为期刊投稿用位图文件。
- `PNG` 主要用于快速预览。
- `PDF` 可用于矢量归档或投稿系统要求的矢量格式。
